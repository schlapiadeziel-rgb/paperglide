# 纸上飞行

一款 Godot 2D 一键飞行小游戏。玩家点击、轻触屏幕或按空格，让折叠纸飞机向上跃起；松开后重力会把飞机拉下。穿过珊瑚、柠檬黄、薄荷、天蓝、薰衣草紫与叶绿色的彩铅素描管道即可得分。每隔一道障碍的缝隙会出现一枚彩色星星贴纸；连续收集三枚触发星章，并获得一次可抵挡碰撞的纸盾。主分仍只按通过障碍数量计算；撞到管道或飞出页面边缘时本轮结束，纸盾会先吸收一次撞击。

## 操作

- 鼠标左键或轻触屏幕：起飞、向上飞、重新开始
- 空格或回车：起飞、向上飞、重新开始
- 标题页“设置”：调整飞行难度、纸飞机涂装、音效开关与音量、三连星纸盾奖励、轨迹涂鸦与笔记本页面主题；选项保存在本机
- 设置页“检查更新”：Android 版检查含 APK 的 GitHub Release；其他平台打开下载页

## v1.4.0 新增

- **飞行轨迹涂鸦**：可选关闭、铅笔虚线、星星尾迹或彩色纸屑。轨迹随飞机经过的路径淡出，采用有界绘制，不产生碰撞或改变计分。
- **笔记本页面主题**：可选横线页、方格页或点阵页；标题页与飞行场景同步使用所选主题，保留原有纸张纹理和云朵涂鸦。
- 新选项与现有难度、涂装等设置一样保存在本机。

## 进阶效果

手绘笔记本纸张纹理、彩铅障碍轮换配色、纸飞机投影与浮层阴影；包含起飞、通过障碍和碰撞三种轻柔音效。难度可选轻松、标准或挑战；多种纸飞机涂装只改变外观。Android 版启动时会检查公开 GitHub Release；仅在发现带 APK 的更新版本时提示，下载与安装由玩家手动确认，不会静默安装。

Android 1.2.1 缩小启动图标并从 APK 中排除网页分享封面；保留 ARMv7 与 ARM64 架构支持。Android 1.2.2 继续从 Web/Android 导出中排除未引用的模板音乐，并从 Android PCK 去除启动图标的导入纹理副本；APK 相比 v1.2.1 减少 4,317,848 字节（5.28%），玩法与双 ARM 支持不变。Android 1.3.0 增加玩家设置菜单、手动更新入口、难度/涂装选项，以及可开关的三连星纸盾奖励。

## 开发

- `npm run check`：运行核心玩法与进阶效果烟雾检查
- `npm run preview:build`：构建游戏预览
- `npm run build`：生成可移植的 Godot Web 导出
- `npm run dev`：启动项目预览服务

游戏内容语言：简体中文。
