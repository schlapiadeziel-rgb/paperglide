# 纸上飞行

一款 Godot 2D 一键飞行小游戏。玩家点击、轻触屏幕或按空格，让折叠纸飞机向上跃起；松开后重力会把飞机拉下。穿过珊瑚、柠檬黄、薄荷、天蓝、薰衣草紫与叶绿色的彩铅素描管道即可得分。每隔一道障碍的缝隙会出现一枚彩色星星贴纸；连续收集三枚触发“星章”提示。主分仍只按通过障碍数量计算，撞到管道或飞出页面边缘时本轮结束。

## 操作

- 鼠标左键或轻触屏幕：起飞、向上飞、重新开始
- 空格或回车：起飞、向上飞、重新开始

## 进阶效果

手绘笔记本纸张纹理、彩铅障碍轮换配色、纸飞机投影与浮层阴影；包含起飞、通过障碍和碰撞三种轻柔音效。星星贴纸与三连星章是额外挑战，不改变主分。每存活一段时间，障碍推进速度会加快、出现间隔会缩短，难度最高提升至第 9 节奏。最佳纪录保存在本地设备中。Android 版启动时会检查公开 GitHub Release；仅在发现带 APK 的更新版本时提示，下载与安装由玩家手动确认，不会静默安装。Android 1.2.1 缩小启动图标并从 APK 中排除网页分享封面；保留 ARMv7 与 ARM64 架构支持。 Android 1.2.2 继续从 Web/Android 导出中排除未引用的模板音乐，并从 Android PCK 去除启动图标的导入纹理副本；APK 相比 v1.2.1 减少 4,317,848 字节（5.28%），玩法与双 ARM 支持不变。

## 开发

- `npm run check`：运行核心玩法与进阶效果烟雾检查
- `npm run preview:build`：构建游戏预览
- `npm run build`：生成可移植的 Godot Web 导出
- `npm run dev`：启动项目预览服务

游戏内容语言：简体中文。
